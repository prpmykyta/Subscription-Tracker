# Subscription Tracker

Backend application for managing subscriptions and tracking recurring expenses.

## Features

- User registration
- JWT authentication
- Create subscriptions
- Update subscriptions
- Delete subscriptions
- View subscription statistics
- PostgreSQL database

## Tech Stack

- Python
- FastAPI
- PostgreSQL
- SQLAlchemy
- JWT
- Docker

## Run locally

1. Clone repository
2. Create .env
3. Install requirements

pip install -r requirements.txt

4. Run application

uvicorn main:app --reload
